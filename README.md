# Recuerdos 🤍

*Para ti, siempre.*

A minimal, dark-themed memories gallery to share videos and photos. Built with pure HTML, CSS, and JavaScript — no frameworks needed.

## How to Use

### 1. Setup your repo
1. Create a new repository on GitHub (e.g., `Recuerdos`)
2. Upload this `index.html` file to the repo
3. Upload your media files (photos & videos) to the same repo

### 2. Configure
Open `index.html` and change this line:

```js
const REPO = 'YOUR_USERNAME/YOUR_REPO';  // e.g., 'modasmadi/Recuerdos'
```

### 3. Add media files
- **Videos**: `.mp4`, `.mov`, `.webm`, `.mkv`
- **Images**: `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`
- Name files with numbers for ordering: `1.mp4`, `2.jpg`, `3.mp4`, etc.

### 4. Enable GitHub Pages
1. Go to your repo → **Settings** → **Pages**
2. Under **Source**, select `main` branch
3. Click **Save**
4. Your site will be live at: `https://YOUR_USERNAME.github.io/YOUR_REPO/`

### Optional: Media subfolder
To keep media in a subfolder, change:
```js
const MEDIA_DIR = 'media/';  // folder name inside repo
```

## Features
- 🖤 Pure black background
- 📹 Video playback with thumbnail preview
- 🖼️ Fullscreen image viewer
- ✨ Smooth scroll animations
- 📱 Fully responsive
